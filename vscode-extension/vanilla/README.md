# CoE5 Modding (.c5m)

Write Conquest of Elysium 5 mods with the editor at your side: every vanilla mod command completes as you type, explains itself on hover, and gets checked before the game ever reads it.

## Install

- **Cursor, VSCodium, Windsurf:** search "CoE5 Modding" in the Extensions panel.
- **VS Code:** download `coe5-modding-vanilla.vsix` from the [latest release](https://github.com/musical-pianist/coe5se-modding-tools/releases/latest), then run "Extensions: Install from VSIX...".

## Features

- **Autocomplete.** Start a line and pick from every mod command that fits the block you're in. Open a quote and pick a monster, weapon, item or spell by string, from vanilla or from your own mod's files.
- **Hover help.** Hover a mod command for what it does and each argument by name, with a link to its page in the manual. A number that stands for a resource, plane or terrain shows what it means.
- **Go to definition.** Jump from a name in quotes to where your mod declares it, in any file of your workspace.
- **Errors before the game sees them.** A misspelled mod command, a quote that never closes, or `--` used as a comment is flagged where you typed it, with the fix one click away.

Using CoE5SE? Install CoE5 Modding (.c5m and .c5se) instead: it holds everything here plus CoE5SE's mod commands, and this edition goes quiet when it's installed.
