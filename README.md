# CoE5SE Modding Tools

[![OpenSSF Scorecard](https://img.shields.io/ossf-scorecard/github.com/musical-pianist/coe5se-modding-tools?label=openssf%20scorecard)](https://scorecard.dev/viewer/?uri=github.com/musical-pianist/coe5se-modding-tools)

Tools for modding Conquest of Elysium 5.

- [`vscode-extension/`](vscode-extension/): CoE5 Modding, the extension for VS Code, Cursor, VSCodium and Windsurf. Autocomplete, hover help, go to definition and typo fixes for .c5m and .c5se files. Download it from the [releases](https://github.com/musical-pianist/coe5se-modding-tools/releases).

## Install

Run the command that matches your OS, then pick Script Extender and all mods and mod tools. The scripts are in the [CoE5SE Installer](https://github.com/musical-pianist/coe5se-installer) repo.

Windows:

```
irm https://raw.githubusercontent.com/musical-pianist/coe5se-installer/main/install.ps1 | iex
```

Mac:

```
curl -fsSL https://raw.githubusercontent.com/musical-pianist/coe5se-installer/main/install.sh | bash
```

Or install by hand: download a mod's zip from https://github.com/musical-pianist/coe5se-modding-tools/releases
