# CoE5SE Modding Tools

[![OpenSSF Scorecard](https://img.shields.io/ossf-scorecard/github.com/musical-pianist/coe5se-modding-tools?label=openssf%20scorecard)](https://scorecard.dev/viewer/?uri=github.com/musical-pianist/coe5se-modding-tools)

Tools for modding Conquest of Elysium 5.

- [`vscode-extension/`](vscode-extension/): CoE5 Modding, the extension for VS Code, Cursor, VSCodium and Windsurf. Autocomplete, hover help, go to definition and typo fixes for .c5m and .c5se files. Download it from the [latest release](https://github.com/musical-pianist/coe5se-modding-tools/releases/latest).
